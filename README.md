## What I've been working on

**Computer vision for healthcare.** A Mask R-CNN pipeline that detects and segments defects in dental X-rays, trained on a corpus merged from 4 open-source datasets (Dice 0.84 on held-out data).

**LLM systems.** RAG and structured-generation pipelines for an EdTech platform, which raised diagram-generation accuracy from 30% to 75%, with model routing to cut latency and token cost.

**Performance engineering.** A custom load balancer in Go in front of a Python backend, sustaining 6M+ requests in 3 hours on a single vCPU, with request validation, leaky-bucket rate limiting, and caching.
